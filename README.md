# discountglitch

High-converting Costco reward bridge lander for organic TikTok / social traffic.

## Local

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Offer URL

Copy `.env.example` to `.env` and set:

```
VITE_OFFER_URL=https://your-cpa-tracking-link
```

All UI is branded **discountglitch** / discountglitch.com. Not affiliated with Costco Wholesale.
